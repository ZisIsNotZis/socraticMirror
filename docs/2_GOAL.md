# 2 · The Goal

## Goal（两句话）

**一个 Agent skill：手里有一张由外部来源锚定、可随前沿更新的 AI/ML 知识网（概念层 DAG + 情景层），用信息增益挑选覆盖面最大的融合题，以开放问答逼人解释、应用、划出失效条件，只从"他说了什么"而不是"他说他会"来判断他懂什么。**

**每次会话结束时，交出一张区分「真懂／虚假掌握／会一半／不会／未测到」的知识地图、每条判断背后的原文证据、以及依赖感知的补课顺序——让人第一次看见自己知识结构的形状和空洞的位置。**

## 优先级（冲突时按此放弃）

1. **知识网的真实性。** 树的上限就是产品的上限：一张模型脑补出来的树，测不出模型自己也没看见的区域。来源必须外部锚定、可追溯、可更新；模型补的洞必须标出来。
2. **选题的数学。** Max Entropy PK：重要性加权的期望熵降 ÷ 成本，一次出题覆盖多个节点（noisy-AND），答错后在覆盖集内二分定位。这是"不是题库"的实质。
3. **判定的诚实。** AI 只产整数分 + 原文引用，公式消化成似然；判不了写"未测到"；level 与证据锐度分轴。任何一条让步，产品就变成算命。
4. **报告的洞见度。** "哪一块是空的"和"先补哪个"必须比"你得了 62 分"更值钱；补课清单要小、要有依赖顺序。
5. （最低）形式上的一切：UI、多模式、教学、社区。

## 模式

**有限（finite）。** 最后一个里程碑 = 通用化：换一个非 ML 领域，只换数据就能跑通。到那里 v1 是 100%，之后的新方向是新的 Goal。

## 交付形态

一个 skill（`SKILL.md` + 少量 reference + 知识网数据 + 一个 stdlib 脚本管状态与选点 + 会话 JSON）。单一角色，无多 agent 编排。可在 pi / 任何支持 skill 的宿主里跑。

## 里程碑（提议，随 Goal 一起确认）

**M1 · 一次真诊断** —— ML/AI 领域，知识网 v0（概念 100–200、情景 30–60，多来源合并 + 标注出处），脚本选点，30–40 问，用户本人跑完。验收：报告里至少有一条是你没想到的（`need_user_review`）。

**M2 · 树可信 + 判定校准** —— 外部关键词表命中率、依赖边抽样正确率、合成锚点集上评分严格单调（完整正确 > 缺边界 > 机制错 > 不知道）、假阴性控制（塞入你铁定会的节点，不被误判为不会）、同一人两次会话结论稳定。

**M3 · 可维护 + 换领域** —— 更新协议（月度 worker 拉新综述/新分类 diff 进树）、树版本与出处审计；换一个非 ML 领域只换数据跑通。

## 先做什么

M1 的第一批：锚点词表与来源清单 → 概念层骨架 + 情景层种子（从教材目录、课程大纲、综述章节、benchmark/赛题、故障复盘抄，不编） → 状态脚本（四状态后验、noisy-AND 更新、重要性加权增益、二分定位）。
