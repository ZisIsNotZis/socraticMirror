## 用户明确说过的话（不可丢）

1. 痛点是：AI 时代里，只有成为精英中的精英才不被淘汰；而要证明"我真的懂"，不能靠做题（太慢、太低效），需要 AI 系统性 top-down 地告诉他知识脉络长什么样、他会什么不会什么。
2. 一个人不可能学习他根本不知道存在的知识——所以**先要有一份系统化、结构化、可随时代更新的知识体系**，AI 才能拿它来拷问你。
3. 要的不是选择题，是自然语言开放作答 + AI 分析这个人的思维、偏向、平衡度。
4. 出题要用 max entropy gain 挑，不是预先设计好的题单。
5. **不要自评标签**（"我会/半会/不确定"）：AI 要从具体描述里判断"你到底会不会"，而不是听你说你会。语气、诚恳、"我会" 这类元陈述权重为零。
6. 直接上最难的、真实的、需要应用的问题；问"解释一下这个概念"是浪费时间。
7. Max Entropy PK 不只是"考哪个点"，还包括**一道题能融进多少知识、能让用户一次吐出多少信息**。
8. 角色只要一个；记忆实时写 JSON；每次提问都重读 JSON 再挑 max gain 的题。
9. 先做 AI/ML/LM 一个方向，之后做成通用的"了解自己知识面"工具；交付形态**是 skill，不要花里胡哨**。
10. 知识必须来自外部；网上资料零散、真假混杂，AI 要负责辨真伪、拼成树/网，缺口用内生知识补（承认这近似幻觉，但没有别的渠道；数据集 TB 级无索引，不碰）。
11. 预算该花花；校准阶段可以用本地 LiteLLM + GitHub Copilot 的便宜模型。

## 讨论中定下的设计（尚未被用户逐条确认，属推断落实）

### 评分：rubric → 总分 → 似然（不是 AI 直接给概率）
- 删掉自评。**"虚假掌握"由断言×机制交叉推出**：断言对而机制错 = 虚假掌握；断言错而机制对 = 会一半。报告类别从 7 类缩到 4 类 + 未测到（"被低估的强项"随自评一起删除）。
- 节点级 rubric 四维，各 0–3，合计 0–12：**辨识 / 机制 / 应用 / 边界**。
- **总分定量级，单维定天花板（硬闸门）**：机制=0 → 最高"知其名"；边界=0 且机制≤2 → 最高"可操作"。防止用廉价维度刷分。
- 总分经一张 12 行查表映射到四状态 `{未知, 知其名, 可操作, 通透}` 的**似然分布**；题型难度偏移：解释 0 / 应用 −1 行 / 边界 −2 行。
- `p_mastery = P(可操作)+P(通透)`；熵算在四状态分布上。
- **confidence 与 level 是两个轴**：每节点存 `level` 分布 + `evidence` 锐度（被几道题、什么题型支撑）。报告要能说"可能可操作，但证据很薄"。
- 校准维（知不知道自己不知道）**不进节点 rubric**，是会话级派生指标（对冲词 vs 实际证据）。

### 边界维 = 回答里有没有自己划出失效条件
不是题型，是任何回答的一个维度。真题条件总是脏的，所以"直接上最难题"恰好让边界维自然暴露，无需专问"它的局限性是什么"（那种题能背）。

### 图结构：三层
```
scenario --instantiates--> concept   多对多；融合题与叶子细节都住这里
concept  --requires-----> concept    DAG；信念传播只走这种边
concept  --relates------> concept    无向可成环；只用于联想出题与报告解释
```
- "两个概念不能融合" = 没有任何 scenario 同时实例化它们。**不用事先声明，查得出。**
- 质检副产品：不在任何 scenario 里的概念 = 考不到的节点（补情景 / 降权 / 标"仅清单覆盖"）。
- 叶子以下的原子不建节点，是 scenario 的 `expected_elements`（3–6 条要点）。图在概念层有限深闭合。

### Max Entropy PK 的正式化
- 一次出题 = (scenario, 覆盖节点集 S, 题型)，|S| ≤ 5。
- 融合题似然是 **noisy-AND**：答对 → S 内全为强正证据；答错 → 只说明"S 里至少一个弱"，逐节点证据弱。于是答对时 ΔH 巨大、答错时 ΔH 很小，目标函数自动偏向大覆盖面。
- 答错时**不换题，在 S 内二分**追问定位断点（log2|S| 步）。粗筛 + 二分 = 面试节奏。
- 目标 = 重要性加权熵降 / 成本：`Σ w_i·ΔH_i / cost`。w_i 同时用于学习路径排序。

### 观察模型：遗漏 ≠ 不会
- 首次遗漏 = 弱负证据；对缺失点做一次定向追问仍空 = 强负证据。似然分两步。
- 判分输入契约：流畅/礼貌/诚恳/"我会" 权重为零；每维分数必须挂原文引用（因果链或具体断言），无引用直接拒收（脚本机械校验）。

### 混合怎么混不亏
- **图与概率在上，文字与语义在下；接缝是一个整数向量（rubric 四维），程序不读自然语言。**
- AI 只产 整数分 + 引用，不产最终数字、不产"大概 70%"。
- 同段回答两种框架各判一次，某维分差 ≥2 → 标低置信，不取平均。
- 判不了写 `unverified`，不许写"不会"。

### 校准（廉价模型当考生）的定位
- 用途是**校准 rubric 与查表**，不是判人。
- 四类合成答案：完整正确 / 正确但缺边界 / 机制错但断言对 / 不知道。要求评分严格单调 (a)>(b)>(c)>(d)，且 (b)-(a) 的落差集中在边界维。做不到 → 改 rubric 或查表，不是改 AI。
- (b) 必须由**强**模型做减法生成；(c)(d) 才用便宜模型 + 关闭 thinking + 剥离工具。

### 知识来源
- 不按文本相似度合并，按**锚点词表**（canonical name + 别名）合并各来源片段 DAG。
- 来源真伪 rubric 化：有版本/日期、有引用、与 ≥2 独立来源是否冲突、前置关系是否符合已知课程结构、是否营销文。
- 模型补洞必须 `source: model / confidence: low`，且在报告里单独标出"树最薄"的区域。
- 免费树质检：用户对某节点问"这是什么？"→ 是节点烂，记为待删。
- 不碰数据集。可批量吞的只有 arXiv 元数据（标题/摘要/分类，GB 级有索引）+ 综述论文章节结构 + 二手整理（教材目录、课程大纲、awesome-list、维基 outline）。

## 明确不做

- 固定题库、选择题、单一大总分排行榜（承自 init.md）
- 多模式 / Gentle 模式切换（承自 init.md）
- 五个 agent 角色（orchestrator/architect/examiner/judge/cartographer）→ 合并为一个角色 + 脚本
- 自评标签（本轮推翻）
- 教学对话、社区题库、花哨 UI、多领域长期画像（MVP 阶段）
- 爬数据集
